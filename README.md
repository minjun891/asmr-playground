# ASMR 놀이터

손끝으로 만지는 소리 놀이터입니다. 이어폰을 끼고 눌러 보세요. 🎧

- 🫧 **뽁뽁이** — 톡톡 터뜨리기 (드래그하면 연달아 터져요)
- ⌨️ **키보드** — 청축·갈축·실제 타건음 (진짜 키보드로도 칠 수 있어요)
- 🍂 **낙엽** — 바스락 부수기 (조각을 계속 부수면 가루가 돼요)
- 🩷 **말랑이** — 꾹꾹 주무르기 (누른 모양이 남고, 초기화할 수 있어요)

폰에서는 브라우저 메뉴의 "홈 화면에 추가"로 앱처럼 쓸 수 있어요. 아이폰은 **무음 스위치**가 켜져 있으면 소리가 나지 않아요.

## 파일

설치나 빌드 없이 정적 파일만으로 동작합니다.

| 파일 | 설명 |
|---|---|
| `index.html` | 게임 전체 (화면, 소리 합성, 4개 씬) |
| `keysamples.js` | 키보드 "실제 타건음" 소리 24개 |
| `leafsample.js` | 낙엽 소리 |
| `sw.js`, `manifest.webmanifest`, `*.png` | 홈 화면 추가, 오프라인 지원, 아이콘 |

## 소리 출처

뽁뽁이, 청축, 갈축, 말랑이 소리는 코드(Web Audio API)로 합성한 소리입니다.
`keysamples.js`와 `leafsample.js`는 아래 유튜브 영상의 녹음에서 일부를 잘라 낸 것입니다.

- 「2026 상반기 사무용 저소음 키보드 타건음 모음 이거 사세요」 (4:00~4:30 구간)
- 「최고의 바스락 소리를 내는 낙엽의 비밀」 (18초 이후 구간)

권리자께서 삭제를 원하시면 이슈로 알려 주세요. 바로 내리겠습니다.
